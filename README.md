# [开发中] 便携监护仪

这是一个开发中的便携监护仪硬件/软件项目，目前处于原型设计与验证阶段。仓库用于保存工程文件、记录开发过程，并邀请他人参与原理图审查、PCB 建议、固件开发、结构设计、测试验证和文档完善。

> 重要说明：本项目尚未经过医疗器械认证或完整工程验证，不能用于诊断、治疗、生命支持或任何正式医疗场景。请仅用于学习、研究和原型开发。

## 希望获得的贡献

本项目允许并欢迎外部贡献者提交 Issue 和 Pull Request。当前 PCB 仍未拉完线，特别欢迎硬件方向的审查和修改建议。

欢迎从以下方向参与：

- 原理图审查
- PCB 布线、电源完整性、模拟前端和抗干扰建议
- 元器件选型与替代料建议
- 电池、电源管理和充电安全建议
- 传感器接口与采样可靠性建议
- 固件驱动、数据采集和通信协议
- 外壳结构、装配方式和便携性改进
- 测试流程、测试记录和文档完善
- 安全风险评估与免责声明完善

适合新贡献者的任务可以标记为 `good first issue`，需要外部帮助的任务可以标记为 `help wanted`。

## 如何参与

1. 先查看已有 Issue，确认是否已有相同问题或建议。
2. 对较大的硬件/软件改动，建议先开 Issue 讨论方案。
3. Fork 本仓库并创建新分支。
4. 提交修改后发起 Pull Request。
5. 在 PR 中说明修改目的、影响范围、验证方式和仍未验证的部分。

更多细节见 [CONTRIBUTING.md](CONTRIBUTING.md)。
